# 독감보다 빠르게, 대응은 확실하게! 교직원 감염병 모의훈련

> 감염병 발생 상황별 교직원 행동요령 숙지와 비상 대응 체계 점검을 위한 현장 중심 훈련

## 1. 프로젝트 소개
- 주 사용자: 학교 구성원(교직원)
- 문제 영역: 행정·업무 효율화
- 결과물 형태: 웹앱
- 완성 상태: 배포 완료(실사용 가능)

## 2. 해결하려는 문제
학교 내 감염병 발생 시 담임교사, 보건교사, 부장교사, 행정실장, 교장·교감 등 구성원별 대응 매뉴얼(체크리스트)이 존재하지만, 평소 서면 숙지만으로는 실제 상황 발생 시 직원별 협력과 신속한 초기 대응이 어렵다는 불편이 있습니다. 또한, 기존 연수는 단순 전달식에 그쳐 구성원들이 자발적으로 참여하고 각자의 역할을 체득하기 힘듭니다.

## 3. 해결 방법
'하나 된 대응, 건강한 학교생활' 슬로건 아래, 학교가 실제로 운영하는 「학생감염병관리조직」(발생감시팀·예방관리팀·학사관리팀·행정지원팀·관리자) 체계를 그대로 반영한 역할 기반 참여형 모의훈련을 개발했습니다. 조(모둠)마다 다른 감염병을 배정해 전체 교직원이 다양한 감염병 대응을 경험하도록 하고, 예방→대응1→대응2→대응3→복구 5단계 시나리오를 조별로 진행하며 각자 맡은 역할의 조치를 선택합니다. 모든 조가 제출하면 진행자가 답을 한꺼번에 공개해 매뉴얼 근거와 함께 비교·토론하는 방식으로, 순위나 감점 없이 20~30분 안에 끝낼 수 있게 만들었습니다.

## 4. 핵심 기능
- 실제 학교 조직도 기반 5개 역할(발생감시팀·예방관리팀·학사관리팀·행정지원팀·관리자) 조 편성, 조별로 서로 다른 감염병 배정 가능
- 예방~복구 5단계 시나리오 진행 및 역할별 대응 문항 선택, 전원 제출 시 동시 공개 후 매뉴얼 근거(rationale) 비교·토론
- 훈련 중 몰입도를 높이는 돌발 상황 카드(와일드카드)
- 감염병 갤러리(모의훈련 대상 7종 감염병의 증상·잠복기·감염기·치료·예방 정보) 및 역할별 대응 체크리스트 미리보기
- 학교 호발 감염병 10종 신속 대응 가이드(인포그래픽 PDF) 사이트 내 임베드 열람
- 훈련 결과(조직도 공백, 대응 공백 체크리스트 등) 기반 맞춤형 가이드북(PDF) 자동 생성

## 5. 사용 흐름
1. 진행자가 학교 정보와 「학생감염병관리조직」을 설정하고, 조(모둠)를 편성하며 조별로 대상 감염병을 지정한 뒤 참가 코드를 발급합니다.
2. 참가자는 참가 코드로 입장해 자신이 속한 조와 맡을 역할을 선택합니다.
3. 단계별 시나리오를 읽고 각자 역할에 맞는 대응 조치를 선택해 조원과 함께 제출합니다.
4. 모든 조가 제출하면 진행자가 전체 공개해 정답 근거와 함께 조별 답변을 비교·토론합니다.
5. 다음 단계로 넘어가며 복구단계까지 반복하고, 훈련 종료 후 결과 화면과 학교 맞춤형 가이드북 PDF를 확인합니다.
